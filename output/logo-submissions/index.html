Logo Submissions

Apache Artemis is looking for a new logo! We welcome submissions from the community.

How to Submit

  1. Fork the artemis-website repository.
  2. Create a folder under src/logo-submissions/ with your name (e.g., src/logo-submissions/jane-doe/).
  3. Add your logo files to your folder. Include your name in all submitted file names.
  4. Optionally add an index.md page in your folder with more details about your submission (see current-logo as an example).
  5. Add your submission to the list below.
  6. Open a pull request.

Guidelines

  • Submissions should be in SVG and/or PNG format.
  • The logo should work well at different sizes (favicon, navbar, full page).
  • Provide both a dark and light background version if possible.
  • Please respect the Apache trademark policy.
