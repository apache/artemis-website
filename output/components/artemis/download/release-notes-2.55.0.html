Artemis 2.55.0 Release Notes

  • A list of commits.

  • Please see the “Versions” chapter in the User Guide for upgrade instructions.

Note: As part of establishing Apache Artemis as an independent project, the Maven groupId has switched to org.apache.artemis.

Note: This release requires use of Java 17 or above.

Bugs Fixed

  • ARTEMIS-6056 - Proper exception if wildcard address is used on producers
  • ARTEMIS-6076 - Auto-delete incorrectly removes addresses with messages when no direct bindings exist
  • ARTEMIS-6084 - Windows: Web console fails to start in Artemis 2.54.0 with InvalidPathException (/C:/…/console.war/WEB-INF)
  • ARTEMIS-6085 - NullPointerException calling MQTTSessionState.getSession()
  • ARTEMIS-6094 - Allow a security role to be composed by a set of other security roles (yaml properties)
  • ARTEMIS-6110 - json broker properties doesn’t load arrays properly
  • ARTEMIS-6119 - Stomp subscriber cannot receive compressed messages

New Features

  • ARTEMIS-6063 - Improve OIDC Login Module: configurable mandatory claims and role mapping

Improvements

  • ARTEMIS-4692 - Allow export of specific queues
  • ARTEMIS-6049 - Mask cluster-password specified via create command
  • ARTEMIS-6057 - support literal matches for FQQN security settings, even if they contain wildcards
  • ARTEMIS-6065 - Make SSL handshake timeout configurable on acceptors
  • ARTEMIS-6067 - Avoid reflection on Downstream core federation. Using Direct instantiation instead.
  • ARTEMIS-6082 - Optimize retryMessage
  • ARTEMIS-6099 - Add log message when configuration reload is complete

Tests

  • ARTEMIS-6115 - Add JMH test for SecurityManagerUtil.authorize

Tasks

  • ARTEMIS-6066 - Deadlock with FederatedQueueConsumerImpl
  • ARTEMIS-6073 - Add SECURITY.md
  • ARTEMIS-6077 - Document threat model
  • ARTEMIS-6092 - Add AGENTS.md guidelines for AI assistants
  • ARTEMIS-6101 - Add cluster credentials to server2 of clustered-grouping example
