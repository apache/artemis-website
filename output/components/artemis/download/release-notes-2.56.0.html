Artemis 2.56.0 Release Notes

  • A list of commits.

  • Please see the “Versions” chapter in the User Guide for upgrade instructions.

Note: As part of establishing Apache Artemis as an independent project, the Maven groupId has switched to org.apache.artemis.

Note: This release requires use of Java 17 or above.

Bugs Fixed

  • ARTEMIS-6008 - Critical Analyzer should not kick in during Failover phase of the broker
  • ARTEMIS-6129 - Broker can’t deal with empty foreign JMS MapMessage
  • ARTEMIS-6146 - LargeMessage Drop through Diver can cause issues on Mirroring
  • ARTEMIS-6159 - A lock coordinator with an unreachable ZooKeeper hangs broker startup and shutdown indefinitely
  • ARTEMIS-6162 - Lock coordinators contend for the lock before the broker is activated
  • ARTEMIS-6172 - HTTP tunneling server async packets starve request replies
  • ARTEMIS-6179 - Deadlock in QueueImpl between management thread (removeMessage) and paging thread when JMX attribute Paused is scraped concurrently
  • ARTEMIS-6184 - AMQP durable subscription unsub does not reutnr error results to the client
  • ARTEMIS-6189 - QoS 1 & 2 message handling is not resilient

Improvements

  • ARTEMIS-6117 - allow the journal file lock check period to be configured from current default 2s
  • ARTEMIS-6158 - AbstractMapPersister for developers
  • ARTEMIS-6163 - Add auto-start attribute and management start/stop operations for lock coordinators
  • ARTEMIS-6173 - Update AGENTS.md
  • ARTEMIS-6201 - Consumer.close on a FQQN should not delete the queue

Tests

  • ARTEMIS-6156 - Add compatibility/security tests
  • ARTEMIS-6178 - Upgrade compatibility test/hornetq to 2.4.11 and add test for topology

Tasks

  • ARTEMIS-6126 - Resolve “system property basedir is configured twice” warnings
  • ARTEMIS-6127 - Remove JDK8/IBM related code
  • ARTEMIS-6128 - Fix typo for Adler32
  • ARTEMIS-6130 - Clarify –consume -1 documentation for artemis check queue command
  • ARTEMIS-6141 - LargeMessageInterruptTest.killProcess() relies on non-portable kill -SIGINT flag
  • ARTEMIS-6145 - Remove unused activemq-stomp dependency from activemq5-unit-tests
  • ARTEMIS-6153 - race in ClusterConnectionImpl causing SF queue loss
  • ARTEMIS-6155 - Decrease github jobs timeout to 60m
