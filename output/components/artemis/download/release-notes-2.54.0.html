Artemis 2.54.0 Release Notes

  • A list of commits.

  • Please see the “Versions” chapter in the User Guide for upgrade instructions.

Note: As part of establishing Apache Artemis as an independent project, the Maven groupId has switched to org.apache.artemis.

Note: This release requires use of Java 17 or above.

Bugs Fixed

  • ARTEMIS-5069 - Sends are still hitting the mirror target on temporary queues
  • ARTEMIS-5956 - Temporary Addresses may leak when consumer is not yet closed
  • ARTEMIS-5971 - Advisories Queues/Topics should not be paged
  • ARTEMIS-5973 - Websocket compression acceptor URI option not handled on XML config load
  • ARTEMIS-5976 - Resource Adapter does not pass clientID to session creation
  • ARTEMIS-5986 - NPE when starting embedded broker without Hawtio
  • ARTEMIS-5987 - singleConnection can be in a bad state
  • ARTEMIS-5997 - SimpleAddressManager.getMatchingQueue not inspecting RoutingType
  • ARTEMIS-6011 - Address fullness not being tracked properly for wildcards
  • ARTEMIS-6031 - Handle credit starvation affecting Core bridge
  • ARTEMIS-6033 - The CLI transfer command doesn’t close the connection factory
  • ARTEMIS-6034 - The CLI perf client command doesn’t close the connection factory

New Features

  • ARTEMIS-5200 - OAuth Bearer Token Support
  • ARTEMIS-5599 - Support key password in Netty SSL
  • ARTEMIS-6030 - Expose Lock Coordinator status through CLI and Management

Improvements

  • ARTEMIS-5949 - Clarify manage permission in default broker.xml
  • ARTEMIS-5958 - ArtemisRbacInvocationHandler removeIfNoPermssion is costly
  • ARTEMIS-5959 - ExternalCertificateLoginModule add support for role assignment
  • ARTEMIS-5961 - Add more proactive clean for the AMQP federation control link address
  • ARTEMIS-6009 - Performance improvement when consuming large messages
  • ARTEMIS-6010 - RBAC authorization speedup
  • ARTEMIS-6051 - Use ~/.artemis_history for shell history by default on Linux

Tests

  • ARTEMIS-5960 - Speed up BridgeTransferTest

Tasks

  • ARTEMIS-5957 - Ensure consistent style for one-line conditionals, etc.
  • ARTEMIS-5974 - Replace FactoryFinder with Java ServiceLoader
  • ARTEMIS-5993 - Add license header to all Service Provider configuration files
  • ARTEMIS-5995 - Remove activemq-broker dependency from integration tests
  • ARTEMIS-6013 - Add unit tests for SecurityManagerUtil
  • ARTEMIS-6020 - Add checkstyle for generic whitespace
  • ARTEMIS-6037 - Refactor handling of cluster credentials
  • ARTEMIS-6058 - Enforce Checkstyle for double spaces
